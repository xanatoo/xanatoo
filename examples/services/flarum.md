# Flarum — forums

[← Services](../services.md)

[Flarum](https://flarum.org/) is a light, modern forum engine. Every Flarum forum serves a
JSON API, so xanatoo reads any of them natively: `flarum:HOST` lists the latest
discussions and `flarum:HOST/d/ID` opens one with all its posts. Any other Flarum forum
works the same way — **Ctrl+L**, `flarum:` and the host name.

Forums checked on 2026-11-21:

- [Flarum Community](flarum:discuss.flarum.org) — the project's own forum, support and extensions
- [Flarum 中文社区](flarum:discuss.flarum.org.cn) — the Chinese Flarum community
- [GrapheneOS discussion](flarum:discuss.grapheneos.org) — the privacy-focused Android distribution
- [Solus forum](flarum:discuss.getsol.us) — the Solus Linux distribution
- [CryptPad forum](flarum:forum.cryptpad.org) — the end-to-end encrypted office suite

More forums show themselves in the [Showcase tag](https://discuss.flarum.org/t/showcase)
of the Flarum community.
