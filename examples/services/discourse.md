# Discourse — forums

[← Services](../services.md)

[Discourse](https://www.discourse.org/) is the forum software of many free-software projects,
programming languages and companies. Every Discourse forum answers the same JSON API, so
xanatoo reads any of them natively: `discourse:HOST` shows the latest topics, `/top` and
`/categories` work too, and a topic opens as a thread with every post.

Forums checked on 2026-11-21 (each answered the API then), by name. Any other Discourse
forum works the same way: **Ctrl+L**, `discourse:` and the forum's host name.
