# Nex — hosts

[← Services](../services.md)

[Nex](nex://nightfall.city/nex/info/specification.txt) is a minimal protocol from the
Nightfall City community: TCP on port 1900, send a path, get back text. A path ending in
`/` is a directory listing whose `=> ` lines are links. xanatoo opens `nex://` addresses
as documents.

Nex hosts answering on 2026-11-21:

- [Nightfall City](nex://nightfall.city/) — the protocol's home, a virtual city of districts
  where everyone can have a page
- [nex.nightfall.city](nex://nex.nightfall.city/) — the same city under its Nex name
- [mozz.us](nex://mozz.us/) — Michael Lazar's Nex corner

Nex is very young and small; more hosts appear in Nightfall City's listings. See also the
[Spartan](spartan.md) and [Gemini](gemini.md) pages.
