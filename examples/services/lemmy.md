# Lemmy — instances

[← Services](../services.md)

[Lemmy](https://join-lemmy.org/) is a federated link aggregator and forum, much like Reddit:
*communities* live on *instances*, and every instance shows communities of the others it
federates with. xanatoo reads Lemmy's API natively (posts, threaded comments, profiles); the
**Lemmy Explorer** (Panels) collects the instances and communities you come across.

| Address | Shows |
|---------|-------|
| `lemmy:HOST/` | the instance's front page (local posts) |
| `lemmy:HOST/?listingType=All` | everything the instance federates (like Reddit's r/all) |
| `lemmy:HOST/c/NAME` | a community — `NAME@OTHERHOST` for one from elsewhere |
| `lemmy:HOST/u/NAME` · `lemmy:HOST/post/ID` | a person · a post with comments |
