# Gopher — holes

[← Services](../services.md)

[Gopher](https://en.wikipedia.org/wiki/Gopher_(protocol)) (RFC 1436, port 70) predates the
web: menus of links, plain text files and search items. Servers are often called
*gopherholes*. xanatoo opens `gopher://` menus and text as documents; a search item asks
for its query in the location bar. In an address, the digit after the host is the item
type — `1` for a menu, `0` for a text file, `7` for a search.
