# PeerTube — instances

[← Services](../services.md)

[PeerTube](https://joinpeertube.org/) is federated video hosting: thousands of independent
servers (*instances*) that follow each other, so one instance also shows videos from
the ones it federates with. xanatoo reads any of them natively — recent videos, channels,
videos with comments, and **▶ Play** in the Media panel. Nothing needs an account.

| Address | Shows |
|---------|-------|
| `peertube:HOST` | recent videos of an instance |
| `peertube:HOST/c/NAME` · `peertube:HOST/a/NAME` | a channel · an account |
| `peertube:HOST/w/ID` | a video, its comments |
| `peertube:HOST/search?search=WORDS` | the instance's search |

Search all of the fediverse's PeerTube videos with [SepiaSearch](peertube:sepiasearch.org/search?search=open+source)
(keyword `pt` in the location bar, e.g. `pt blender`). See also [media.ccc.de](mediaccc:), the
Chaos Computer Club's talk archive, and the other [video services](../services.md#Video).
